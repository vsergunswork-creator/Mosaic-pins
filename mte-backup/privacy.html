Privacy Policy

Effective date: 18 September 2026

1. Operator and purpose

MTE Backup is a private administrative utility operated by Vitalijs Serguns. It is used to create and store backup copies for Mosaic Trading Engine in the operator's own Google Drive account. It is not offered as a public service.

2. Google data accessed

MTE Backup uses Google OAuth and requests the https://www.googleapis.com/auth/drive.file scope. This scope is used only to create, upload, verify, list, update, and remove backup files that the application creates or manages for its backup purpose.

The application does not request broad access to all files in the Google Drive account and does not use Google data for advertising, profiling, or marketing.

3. Data processed by the backup system

The backup workflow may process:

  • PostgreSQL backup archives generated by Mosaic Trading Engine;
  • SHA-256 checksum files used to verify backup integrity;
  • backup metadata such as creation time, host name, release identifier, database migration version, and aggregate table counts;
  • OAuth credentials and tokens required to authorize the Google Drive connection.

4. How Google user data is used

Information received from Google APIs is used solely to provide backup storage and recovery-related file operations for the operator. Google user data is not sold, rented, used for advertising, or transferred to unrelated third parties.

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

5. Storage and security

OAuth configuration and tokens are stored on the operator's private server with restricted file permissions. Backup archives are stored locally on that server and in the operator's own Google Drive account. Access to the server and backup configuration is restricted to the operator.

6. Retention and deletion

Local automatic backups are subject to the operator's configured retention policy. Copies stored in Google Drive remain under the operator's control and may be deleted there when no longer needed. OAuth access can be revoked at any time through the operator's Google Account permissions, and the local rclone configuration can be removed from the server.

7. Sharing

MTE Backup does not intentionally make backup files public and does not share Google Drive data with advertisers or data brokers. Data may be disclosed only if required by applicable law or necessary to protect the security of the system.

8. Contact

Questions about this privacy policy or MTE Backup can be sent to support@mosaicpins.space.
