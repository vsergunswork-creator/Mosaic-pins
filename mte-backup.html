About MTE Backup

MTE Backup is a private administrative utility used by the owner of Mosaic Trading Engine to keep verified PostgreSQL backup copies in a user-controlled Google Drive account.

This is not a public cloud-storage service and it is not a trading service. It exists only to automate backup and recovery for the owner's own system.

What the application does

  • Creates verified database backup archives, checksums, and backup metadata.
  • Uploads those backup files to a dedicated location in the owner's Google Drive.
  • Uses Google OAuth only to authorize that backup operation.

Google Drive access

MTE Backup requests the narrow Google Drive scope drive.file. The application uses this access only for backup files it creates or manages for this purpose. It does not use Google Drive data for advertising, profiling, or resale.
